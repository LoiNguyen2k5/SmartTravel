# Detailed Impeccable Command Catalog

| Command | Category | Purpose | When to Use |
| :--- | :--- | :--- | :--- |
| `/impeccable init` | Foundation | Project onboarding & context recording | Run once at project start to document product truth in `PRODUCT.md`. |
| `/impeccable document` | Foundation | Design system extraction | Generate or update `DESIGN.md` based on active code styles & tokens. |
| `/impeccable extract` | Foundation | Token & component harvesting | Isolate inline values into reusable tokens and component primitives. |
| `/impeccable shape` | Foundation | UX/UI pre-code architecture | Plan content flow, wireframe relationships, and state requirements. |
| `/impeccable craft` | Foundation | Full design lifecycle | End-to-end shape, implement, and visually iterate on a feature. |
| `/impeccable critique` | Review | High-level UX evaluation | Review visual hierarchy, narrative clarity, emotional tone, cognitive load. |
| `/impeccable audit` | Review | Technical compliance scan | Inspect accessibility (WCAG AA), responsive breakpoints, and contrast. |
| `/impeccable polish` | Review | Final shipping pass | Align micro-spacing, verify token consistency, fix edge blemishes. |
| `/impeccable bolder` | Tuning | Elevate design courage | Transform bland, timid, or generic screens into confident, memorable UI. |
| `/impeccable quieter` | Tuning | Visual noise reduction | Tone down overly loud, hyper-saturated, or chaotic interfaces. |
| `/impeccable distill` | Tuning | Radical simplification | Strip away unnecessary containers, dividers, and decorative clutter. |
| `/impeccable delight` | Tuning | Micro-moments of joy | Craft delightful feedback, hover nuances, and satisfying tactile feel. |
| `/impeccable overdrive` | Tuning | High-end visual effects | Implement advanced visual techniques: shaders, complex masks, fluid glass. |
| `/impeccable typeset` | Frontend | Typography overhaul | Select complementary font pairings, dial in optical rhythm and measure. |
| `/impeccable layout` | Frontend | Spatial composition | Perfect grid alignment, responsive flexbox layout, and asymmetric spacing. |
| `/impeccable colorize` | Frontend | Strategic color harmony | Apply cohesive color ramps, atmospheric tinting, and contrast safety. |
| `/impeccable animate` | Frontend | Motion design | Implement natural, physics-inspired easing curves without bouncy gimmicks. |
| `/impeccable clarify` | Frontend | UX copy & messaging | Eliminate confusing phrasing, ambiguous button text, and harsh error text. |
| `/impeccable harden` | Frontend | Edge-case resilience | Bulletproof empty states, error boundaries, text overflow, and i18n. |
| `/impeccable onboard` | Frontend | First-run experience | Guide new users through smooth activation, tooltips, and empty states. |
| `/impeccable adapt` | Frontend | Cross-device ergonomic fit | Adapt touch targets, keyboard navigation, and mobile viewport nuances. |
| `/impeccable optimize` | Frontend | Performance & smoothness | Eliminate layout thrashing, excessive re-renders, and bloated CSS. |
| `/impeccable live` | Frontend | Live browser variant mode | Interactively experiment with visual variants in a running browser dev server. |
